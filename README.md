# iOS 捷徑：大眾運輸自動降噪

## 目的
坐公車或捷運時，一鍵讓 Sony WF-1000XM6 切換到降噪模式。

## 建立步驟（iPhone 捷徑 App）

1. 打開「捷徑」App，點右上角 + 建立新捷徑。
2. 搜尋並加入動作「設定藍牙裝置音訊」，選擇 Sony WF-1000XM6。
3. 在同一個動作的選項裡，音訊模式選「降噪」（Noise Cancellation）。若沒有直接選項，改用「設定音訊輸出」後接「設定媒體音量」以外的方式：
   - 動作「控制 Sony 耳機」→ 若系統有提供，選降噪。
   - 否則用「開啟 App」打開 Sony Headphones Connect，手動切（較不理想）。
4. 捷徑名稱改成「公車降噪」。
5. 回到捷徑主畫面，長按這個捷徑 → 加入主畫面，之後一鍵就能用。

## 自動版（選用）

想要上車自動切換：

1. 捷徑 App → 自動化 → 點 +。
2. 觸發條件選「抵達」，地點設你常坐的公車站或捷運站。
3. 動作一樣是「設定藍牙裝置音訊」→ Sony WF-1000XM6 → 降噪。
4. 關閉「執行前詢問」，讓它靜默執行。

## 注意

- Sony 耳機的降噪切換依賴 iOS 對 LE Audio / 藍牙音訊設定的支援，不同 iOS 版本選項名稱可能不同。
- 若「設定藍牙裝置音訊」沒有降噪選項，代表該 iOS 版本無法由捷徑直接控制，只能開 Sony Headphones Connect App。
