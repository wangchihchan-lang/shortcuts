# iOS 捷徑：大眾運輸自動降噪

## 目的
坐公車或捷運時，一鍵讓 Samsung Galaxy Buds4 Pro 切換到降噪模式。

## 建立步驟（iPhone 捷徑 App）

1. 打開「捷徑」App，點右上角 + 建立新捷徑。
2. 搜尋並加入動作「設定藍牙裝置音訊」，選擇 Samsung Galaxy Buds4 Pro。
3. 在同一個動作的選項裡，音訊模式選「降噪」（Noise Cancellation）。若沒有直接選項：
   - 動作「開啟 App」→ 打開 Samsung Wearable（三星穿戴）App，手動切換降噪（較不理想）。
4. 捷徑名稱改成「公車降噪」。
5. 回到捷徑主畫面，長按這個捷徑 → 加入主畫面，之後一鍵就能用。

## 自動版（選用）

想要上車自動切換：

1. 捷徑 App → 自動化 → 點 +。
2. 觸發條件選「抵達」，地點設你常坐的公車站或捷運站。
3. 動作一樣是「設定藍牙裝置音訊」→ Samsung Galaxy Buds4 Pro → 降噪。
4. 關閉「執行前詢問」，讓它靜默執行。

## 注意

- Buds4 Pro 的降噪切換依賴 iOS 對藍牙音訊設定的支援，不同 iOS 版本選項名稱可能不同。
- 三星耳機在 iOS 上的功能支援通常比 Android 少，若「設定藍牙裝置音訊」沒有降噪選項，建議改用 Android 手機的「模式和捷徑」或 Bixby 語音指令「切換降噪」，體驗會更順。
- 若 iPhone 上真的無法直接控制，可以考慮在 Android 手機上設定「抵達大眾運輸」自動切換，或使用 Tasker 類 App 做更精細的藍牙裝置偵測。
