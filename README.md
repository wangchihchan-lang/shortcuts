# Samsung Galaxy Buds4 Pro 自動切換降噪／環境音優化指南

## 目的
希望在「走路」時自動切換到環境音（通透）模式，在「坐公車／捷運」時自動切換到降噪（ANC）模式。

---

## 一、iOS 捷徑（基礎版，限制較多）

1. 打開「捷徑」App → 新建捷徑。
2. 加入「設定藍牙裝置音訊」→ 選 Samsung Galaxy Buds4 Pro → 模式選「降噪」或「環境音」。
3. 長按捷徑 → 加入主畫面，一鍵手動切換。
4. 自動化：使用「抵達」觸發（公車站地點）做簡易自動，但無法精準區分走路與坐車。

**限制：** iOS 對三星耳機控制力較弱，建議改用 Android。

---

## 二、Android 優化（推薦，你有 Galaxy Z Fold 7）

### 1. 先開啟耳機本身智慧功能（Galaxy Wearable App）
- 打開 Galaxy Wearable → Buds4 Pro → 噪音控制
- 啟用 **Adaptive ANC 2.0**（自適應降噪）
- 開啟「自動切換到環境音」：
  - Voice Detect（說話時自動環境音）
  - Siren Detect（警報時自動環境音）
- 這些已經能解決大部分日常場景。

### 2. 三星內建「模式和例行」（Modes and Routines）
這是最推薦的無需額外 App 方式：

**走路時 → 環境音：**
1. 設定 → 模式和例行 → 例行 → 新增
2. 觸發條件：活動 → 選「步行」或「走路」
3. 動作：藍牙裝置 → Galaxy Buds → 切換到「環境音」模式
4. 可再加上「藍牙已連接 Buds4 Pro」為條件

**坐公車／交通工具 → 降噪：**
1. 觸發條件：活動 → 選「乘車」或「交通工具上」（三星活動識別支援）
2. 或用「移動速度」（若有選項）+ 藍牙已連接
3. 動作：切換到「降噪」模式

**額外優化：**
- 加上「電量低於 30%」時關閉自適應，節省電量。
- 到家或到公司地點時自動設成環境音。

### 3. 進階：Tasker 或 MacroDroid（更精準速度偵測）
若三星內建活動識別不夠準：
- **MacroDroid**（推薦，介面簡單）：
  - 觸發：速度（GPS）> 15 km/h 且持續 30 秒 + 藍牙已連接 → 切降噪
  - 速度 < 5 km/h 且步數增加 → 切環境音
- **Tasker**：用 Location + Activity Recognition 或加速度計債測做更細的進階自動化。

### 4. Bixby 語音快捷指令
- 對手機說：「切換降噪」、「開啟環境音」、「自適應模式」
- 可在 Bixby 例行裡設定自訂語音命令。

---

## 三、額外實用優化建議

1. **耳塞貼合：** 使用適合尺寸耳塞，密封度對 ANC 效果影響很大。
2. **電量管理：** 長時間坐車建議開 Adaptive，不要全時間最大降噪。
3. **通話優化：** 開啟 Voice Detect + 通話中使用環境音，讓通話更自然。
4. **風噪：** 走路時若環境音太噪，可在 App 裡調低環境音音量。
5. **備份：** 建議同時設定手動捷徑或主畫面快捷方式當備份。

---

## 測試建議
1. 先開啟耳機 Adaptive + Voice/Siren Detect，用一兩天看是否已足夠。
2. 再設定三星「模式和例行」做走路／乘車切換。
3. 若仍不準，再安裝 MacroDroid 做速度偵測。
